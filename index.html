Verify a download

Save the asset and the SHA256SUMS file for the same version in one directory. On Linux, use SHA-256 to verify the files you downloaded. Each should report OK.

curl -fLO https://github.com/fibegg/fibe-core/releases/download/0.1.0-e2bcfe32/SHA256SUMS
curl -fLO https://github.com/fibegg/fibe-core/releases/download/0.1.0-e2bcfe32/frontend.tar.gz
sha256sum --ignore-missing --check SHA256SUMS

Compose quick start

Save compose.yaml and run these commands with Docker Compose. The setup service prepares the local database and the UI image supplies the frontend assets.

docker compose up -d
docker compose ps

Open http://localhost:8080. If the setup screen asks for a token, generate one from the running API.

docker compose exec api fibe-api --data-dir /data setup token
